## Overview

Frontend work for a 3D e-commerce platform. The public side sells personalised 3D replicas; the admin side runs orders, franchises and inventory; the desktop app lets a franchise manage orders and capture the 360-degree photos used to build each customer's model.

## My part

I built and maintained the Next.js marketing site and the React.js admin site, integrated Three.js for the model viewer, and developed the franchise desktop application with React.js and Node.js.
